These are exact selected ZIP-member bytes. `fluss-reader/historical-records.json` lists their original member names and hashes. The new `fluss-reader.tar.gz` is a newly assembled public selection; `archive-binding.json` binds every member to current source bytes. Its new archive hash is not the private historical ZIP hash and is not a new execution seal. No private ZIP, SQLite/WAL/SHM binary, full command journal, Maven output, native host log, operator document, jar or distribution is shipped.

The experiment uses a deterministic classifier, synthetic ticket, one active worker per job, one bucket and one replica, with Fluss surviving every worker failure. `client.writer.acks=all`; `table.log.ttl=0ms` disables time-based deletion. Replay has an exclusive high-watermark with writers stopped; offsets are per bucket. Earliest-prefix gaps reject. The scan contract permits an empty-batch advance, but none was observed. B2 kills after service commit; it does not test a lost HTTP response or network timeout. The HTTP service is an atomic SQLite-backed stand-in with action-ID, canonical-payload and receipt validation. These results establish neither host-loss recovery, concurrent-worker safety nor exactly-once external effects. A real model could return different output or cost money; email adds another effect boundary.

The executable source is the unchanged 12-file set in `source-manifest.json`: `pom.xml`, three Python scripts and eight Java files. `E2E_SPEC.md` is the prewritten contract. Historical pins: native Linux amd64; Fluss 1.0.0; Temurin 17.0.15+6; Maven 3.9.9; Python 3.12.3; SQLite 3.45.1. The Maven image digest, jar/class hashes and plugin/dependency versions are retained in the selected binding records and source.
